# AI Use Policy

AI tools (Claude, ChatGPT, Copilot and others) are welcome in this course as a **tutor**. They are not allowed to do the project for you. The goal is that you can explain and defend every part of your own work.

## Allowed

- Ask for an explanation of a concept, an error message, or a piece of code.
- Ask for a hint or a different way to think about a problem.
- Ask the AI to review code you wrote and point out problems.
- Ask for a short syntax example on a different table or toy data.
- Get full help with setup: `.env`, connection errors, packages, git, Quarto rendering.

## Not allowed

- Having an AI write your analysis, features, model, evaluation, or report text.
- Having an AI write your project plan, conclusions, or weekly log.
- Pasting AI output you do not understand.

## Be ready to explain it

You may be asked to explain any line of your work, or to rebuild a step, live in class. If you cannot, the work does not count as yours.

## Claude Code in this repo

This repo configures Claude Code as a tutor (see `CLAUDE.md` and `.claude/`). It gives hints instead of finished answers. That is a guardrail, not a lock. Other tools do not read these files, and you can edit them in your own fork. **The rules above apply to you whichever tool you use and whatever the tool is willing to do.**
